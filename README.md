# RTOS-Controlled Intelligent Space Utilization and Display System for Auditoriums Using STM32

STM32-based auditorium occupancy monitoring and space utilization system with real-time people counting and display management.

## Overview

An embedded system designed to monitor auditorium occupancy and display real-time space utilization information. The system uses an STM32 microcontroller and ultrasonic sensors to detect people entering and leaving the auditorium, maintain an occupancy count, and present the information through an LCD display. The project explores both bare-metal programming and RTOS-based task management for embedded applications.

## Key Features

* Real-time auditorium occupancy monitoring
* People counting using ultrasonic sensors
* Entry and exit detection
* LCD-based occupancy status display
* Bare-metal and RTOS-based implementation approaches
* Modular embedded software architecture

## Hardware Components

* STM32F407VGT6 Microcontroller
* HC-SR04 Ultrasonic Sensors
* 16×2 LCD with I²C Interface
* Power Supply
* Connecting Wires and Supporting Circuitry

## Software Components

* Embedded C
* STM32CubeIDE
* CMSIS
* FreeRTOS
* GPIO and I²C Peripheral Programming

## Tech Stack

STM32F407VGT6 | Embedded C | CMSIS | FreeRTOS | Ultrasonic Sensors | I²C LCD
